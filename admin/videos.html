    Storage setup & test

    1. Test the connection

    Sends a tiny file from this phone to the video storage and removes it again. Run it after any change, or if uploads fail.

      2. One-time setup (only if the test says uploads are blocked)

      Backblaze has to be told that this website is allowed to send videos to your storage (a “CORS” rule). Setting it needs Backblaze's master key, once. Never paste that key into this page or send it to anyone. It goes into Vercel, where only the server can read it, and comes out again afterwards.

      1. In Backblaze → Application Keys, tap Generate New Master Application Key. Copy the Key ID and the Application Key (it is shown only once).
      2. In Vercel → your project → Settings → Environment Variables, add two variables, B2_SETUP_MASTER_KEY_ID and B2_SETUP_MASTER_KEY. Choose Production only, and switch on Secret (some screens call it Sensitive) so the value can't be read back.
      3. Redeploy (Deployments → ⋯ → Redeploy). Variables only reach the website after a redeploy.
      4. Open this page at https://nd-flow-plumbing.vercel.app/admin/videos.html, not at a preview address, and tap Configure upload permissions. The server uses the key; this page never sees it.
      5. Right after it says Done: delete both B2_SETUP_… variables in Vercel, redeploy, then tap Generate New Master Application Key in Backblaze again. That cancels the temporary key. Your upload keys (STORAGE_KEY_ID, STORAGE_APP_KEY) keep working.
      6. Come back and run Test storage (step 1).
